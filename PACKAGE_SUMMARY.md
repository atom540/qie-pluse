## ⚡ **Quick Start (5 Minutes)**

### **1. Setup Environment**
```bash
conda create -n ai-risk-oracle python=3.10
conda activate ai-risk-oracle
pip install -r requirements.txt
```

### **2. Configure System**
```bash
cp .env.example .env
# Edit .env with your API keys (CoinGecko, Alpha Vantage)
```

### **3. Train AI Model**
```bash
python train_model.py --training-months 11 --extended-training
```

### **4. Launch System**
```bash
# Terminal 1: Backend
python start_api_server.py --port 8001

# Terminal 2: Frontend
python start_frontend.py

# Access: http://localhost:3000
```
